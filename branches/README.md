# Notes par branche

Un fichier par lot : `branches/<nom-de-la-branche>.md` (ex. `branches/reperer.md`).

Il contient :
- le contexte propre au lot (matériel, commandes, choix techniques) ;
- la section `## Où on en est`, mise à jour automatiquement par `/fin-de-seance`.

Chaque équipe ne modifie que **son** fichier : pas de conflit quand les branches sont fusionnées dans `main`.
